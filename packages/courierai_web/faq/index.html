App

What is CourierAI?

CourierAI is a bring-your-own-keys LLM chat app, with a focus on security, privacy, and performance.

Who is CourierAI for?

If you've ever run into subscription plan rate limits, you'd rather pay for the tokens you actually use, or you want access to frontier LLMs without paying monthly subscriptions to every provider, then CourierAI is for you.

Do I need a CourierAI account?

No, CourierAI doesn't have accounts. You only need API keys from the providers you want to use.

What browsers does CourierAI support?

Any Chromium-based browser (Chrome, Edge, Brave, etc).

Why do I need to install an extension?

The CourierAI website is just static files served from a CDN - there are no CourierAI servers that your keys, chats, or API requests ever pass through. The extension acts as that backend: it stores your API keys and sends your requests directly to the provider.

Why can't the website just call the APIs directly?

Some providers allow this, such as with Anthropic's 'anthropic-dangerous-direct-browser-access' request header option. However, it's dangerous because the website has to store your API keys, where any script running on the page can read them. Our extension keeps your keys isolated from every website, even the official CourierAI website, by design.

What providers does CourierAI support?

CourierAI currently supports OpenAI, Anthropic, Google, and OpenRouter, with more providers planned. Let us know if there's a specific provider you'd like us to add!

Can I upload pdfs/images/files?

Yes! CourierAI supports file uploads. Different providers support different file types, see provider API documentation for details.

Does CourierAI work on mobile?

CourierAI works on devices that can install the browser extension, such as desktops, laptops, and Chromebooks. Most phones cannot install browser extensions. Let us know if you'd like a mobile app!

How is this different from using a provider's web app?

Provider web apps are built around that provider's own models, plans, and usage limits. CourierAI is a bring-your-own-key client: you can use multiple provider APIs in one customizable chat UI, pay as you go, and avoid subscription-plan usage limits.

How is this different from using other BYOK apps?

CourierAI is built to be lightweight, fast, and low-friction. There's no account, no desktop app, no CourierAI server between you and the provider. You install the browser extension, open CourierAI.net, add your API keys, and it just works.

Privacy, Security, & Data

Does CourierAI see my conversations?

No. Your messages, attachments, system prompts, and model/request settings are sent from the website UI to the browser extension, then directly to the provider and back to the UI. Your conversations never touch our servers.

Does CourierAI host any models?

No, CourierAI does not host models or run inference servers.

What data do you collect?

The bare minimum needed to host the site. We use AWS CloudFront as our CDN, which necessarily processes your IP address in transit to deliver the site. CloudFront also provides aggregate reports on referrer domains, device type, browser, operating system, and country/US state in a rolling 60-day window. We do not retain any per-request data. See our privacy policy.

How does CourierAI store and protect my API keys?

We rely on the Chromium extension security model, which isolates your stored API keys from websites and other extensions. Once a key is saved, CourierAI.net can ask the extension to make a provider request or delete the key, but it cannot read the key back - we intentionally do not expose any code path for reading saved keys. The extension keeps control of the key and only sends it to the provider you choose when making an API request.

Are my chats, API keys, and settings synced?

Chats and API keys stay local to your device. Settings will sync through your browser account if you're signed in. If sync is off, or if your browser keeps extension data local, everything is stored locally on your device and does not sync.

Can I export my chat history?

Yes, you can export chats individually by clicking on the gear button next to the chat in the sidebar or via bulk export in settings.

Can I import chats?

Yes, we currently support importing CourierAI, LM Studio, and SillyTavern chats. Let us know if there's another app you'd like to import chats from!

Can I delete my data?

Yes. You can delete chats individually via the gear button next to the chat in the sidebar, you can clear API keys individually in settings, and you can delete all data via settings or by clicking on the extension icon in your browser toolbar. You can also uninstall the extension from your browser, which deletes all of your data as well.

Is CourierAI open source software?

CourierAI is source available software, see our GitHub.

Costs

Is CourierAI free?

The CourierAI website and extension are free to use for personal use and qualifying small-business use. API usage is billed by the respective providers. If you would like to use CourierAI for larger commercial use, please reach out to blake@courierai.net. For details, see the license.

How much does using a provider API through CourierAI cost?

Provider pricing is based on the number of input and output tokens used. Your cost depends on the provider, model, conversation length, attachments, and how much you use it. Lightweight models can be very cheap for everyday chats; large frontier models, long contexts, and heavy daily use cost more.

Does CourierAI add a markup to provider API costs?

No, CourierAI does not add a markup or charge per request. Your API usage is billed directly by the providers you use.

Are there free models I can use with CourierAI?

Yes! OpenRouter offers access to free models, so you can use CourierAI without paying for API usage. Note that free model providers may retain or train on your prompts and responses, and some may publish your prompts and responses if you opt in.

Support & Feedback

What if I want to use a provider/model that isn't listed on the site?

Let us know! We're working on adding support for more providers.

I found a bug or ran into an error. Where do I report it?

Please open an issue on our GitHub and include what happened, what you expected, your browser, and any error message you saw.

I like CourierAI. How can I help?

Tell your friends! Star the project on GitHub, and share feedback in GitHub Issues. You can also turn on OpenRouter request app tagging in advanced settings, which credits CourierAI on OpenRouter's public app leaderboard.
